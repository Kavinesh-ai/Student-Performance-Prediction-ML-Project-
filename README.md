# Student Performance Prediction

## Overview

This project predicts student performance using **Linear Regression** based on study hours and previous scores.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-Learn

## Dataset Features

* Hours Studied
* Previous Scores
* Performance Index (Target)

## Workflow

1. Load Dataset
2. Data Preprocessing
3. Train-Test Split
4. Linear Regression Model
5. Prediction and Evaluation

## Results

The model predicts student performance and is evaluated using the **R² Score** metric.
